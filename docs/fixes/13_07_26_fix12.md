# 13/07/2026 - Fix 12 - Reparo de cffi, cryptography e matplotlib no .venv

## Problema

Ao iniciar o dashboard Streamlit pelo `iniciar_sellas.bat`, a aplicacao falhava durante a cadeia:

```text
dashboard.py -> main.py -> docx_parser.py -> google.genai -> google.auth -> cryptography
```

Erro observado:

```text
ModuleNotFoundError: No module named '_cffi_backend'
```

Depois do reparo dessa dependencia, o import completo do dashboard revelou outro binario quebrado:

```text
ImportError: cannot import name '_c_internal_utils' from partially initialized module 'matplotlib'
```

## Causa

O `.venv` ainda continha pacotes com extensoes nativas inconsistentes para o Python 3.12 atual do projeto Sellas.

## Correcao aplicada

- Reinstalado `cffi`.
- Reinstalado `cryptography`.
- Reinstalado `matplotlib` e suas dependencias nativas.
- Adicionados `cryptography` e `cffi` ao `requirements.txt` para deixar essa dependencia explicita.

## Validacoes executadas

- `import _cffi_backend`: OK.
- `import cryptography.exceptions`: OK.
- `from google import genai`: OK.
- `import main`: OK.
- `import app.web.dashboard`: OK.
- `pytest tests/bhave -q`: 13 testes passaram.
- `py_compile` de `api.py`, `main.py`, `docx_parser.py`, `pei_docx.py` e `dashboard.py`: OK.

## Resultado esperado

O dashboard Streamlit nao deve mais falhar com `_cffi_backend` nem com `_c_internal_utils` ao iniciar pelo `iniciar_sellas.bat`.
