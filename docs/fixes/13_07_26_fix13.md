## Modelo matematico para habilidades/objetivos

- Agrega a independencia media por mes.
- Ajusta regressao linear mensal:

```text
y_t = beta0 + beta1.t
```

- Calcula tendencia mensal em pontos percentuais.
- Projeta os proximos meses.
- Calcula probabilidade de atingir o criterio definido:

```text
P(y >= criterio) = 1 - Phi((criterio - previsao) / sigma)
```

- Exemplo validado: para uma serie mensal `70%, 20%, 100%`, a previsao do mes seguinte ficou em `93,33%`.

## Modelo matematico para comportamento-problema

- Agrega contagem total ou taxa media por mes.
- Usa regressao log-linear para manter previsoes nao negativas:

```text
z_t = ln(y_t + 1)
z_t = alpha + beta.t
previsao = exp(alpha + beta.t) - 1
```

- Calcula probabilidade de aumento no proximo mes.
- Calcula probabilidade de reducao conforme meta percentual escolhida.
- Gera ranking de risco comportamental.
