# 13/07/2026 - Fix 15 - Contraste e tema claro do Streamlit

## Problema

O dashboard Streamlit estava com fundo escuro e textos muito claros sobre cards claros, deixando a leitura praticamente impossivel.

## Causa provavel

O `iniciar_sellas.bat` executa o Streamlit a partir de `app/web`, entao o tema em `.streamlit/config.toml` na raiz podia nao ser aplicado nessa execucao. Alem disso, classes dinamicas do Streamlit/BaseWeb estavam sobrescrevendo parte do CSS customizado.

## Correcao aplicada

- Atualizado `.streamlit/config.toml` com tema claro de alto contraste.
- Criado `app/web/.streamlit/config.toml` com o mesmo tema, garantindo que o Streamlit leia a configuracao quando iniciado dentro de `app/web`.
- Reforcado `app/web/assets/style.css` com:
  - fundo claro global;
  - texto escuro global;
  - contraste explicito para header, cards, patient strip, formulas e tabelas;
  - seletores especificos para Streamlit/BaseWeb;
  - bloco final `Final contrast lock` para impedir texto branco em superficies claras.

## Validacoes executadas

- `py_compile app/web/dashboard.py`: OK.
- API e Streamlit temporarios responderam por HTTP antes do ajuste final.
- Processos temporarios de validacao foram encerrados.

## Observacao

Para ver a mudanca, feche as janelas atuais do Streamlit/API e abra novamente pelo `iniciar_sellas.bat`, porque o tema TOML e carregado na inicializacao.
