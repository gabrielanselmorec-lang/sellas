## Estrutura da leitura por IA

1. Leitura descritiva dos padrões, com números e limites da amostra.
2. Hipóteses funcionais concorrentes, nunca apresentadas como confirmadas.
3. Evidências compatíveis, contrárias ou ausentes para cada hipótese.
4. Dados adicionais necessários para avaliação funcional.
5. Síntese cautelosa para decisão do supervisor humano.

## Limites clínicos e de privacidade

- Função preenchida pela equipe, associação estatística e função demonstrada experimentalmente permanecem conceitos separados.
- A leitura da IA é uma opinião exploratória para supervisão, não uma conclusão funcional.
- Dados enviados ao provedor são desidentificados e não contêm o nome do paciente.
- A chamada externa acontece somente após clique do usuário.
- O Excel não é fonte de entrada. O banco Supabase continua sendo a fonte de verdade.
