# 13/07/2026 - Fix 11 - Reparo do psycopg2 no .venv

## Problema

Ao iniciar o `iniciar_sellas.bat`, a API FastAPI falhava durante o carregamento do `api.py` com:

```text
ModuleNotFoundError: No module named 'psycopg2._psycopg'
```

## Causa

O pacote `psycopg2-binary` estava presente no `.venv`, mas o binario interno `_psycopg` nao estava disponivel/correto para o Python 3.12 do ambiente.

## Correcao aplicada

- Reinstalado `psycopg2-binary` no `.venv` com o wheel Windows/Python 3.12.
- Mantido `psycopg2-binary` no `requirements.txt`, que ja estava declarado.

## Validacoes executadas

- `import psycopg2`: OK.
- `import api`: OK.
- `uvicorn.Config("api:app").load()`: OK.
- `py_compile` de `api.py`, `app/data/models.py` e `app/web/dashboard.py`: OK.

## Resultado esperado

O `iniciar_sellas.bat` nao deve mais falhar no erro `No module named 'psycopg2._psycopg'` ao iniciar a API.
