# Fix 2 - Motor ABC fechado por intervalos

Data: 14/07/2026

## Problema original

O modelo ABC antigo misturava registro, analise descritiva e predicao. Isso permitia interpretacoes indevidas, como tratar associacao estatistica como funcao comportamental, usar consequencia do mesmo intervalo como preditor do comportamento anterior e confundir ausencia de registro com ausencia confirmada.

## Alteracoes feitas

- Criado modulo ABC fechado independente.
- Separadas tres tarefas:
  - registro do intervalo observado;
  - analise descritiva de associacoes ABC;
  - preparacao temporal para predicao futura.
- Adicionada semantica explicita para `true`, `false`, `null`, `not_observed` e `not_applicable`.
- Implementado arredondamento temporal deterministico para baixo com timestamp completo e UTC.
- Removida dependencia de data fixa de outubro de 2025.
- Finais de semana sao incluidos por padrao.
- Denominador das metricas usa apenas intervalos efetivamente observados.
- Implementadas metricas descritivas:
  - `P(B)`;
  - `P(B|A)`;
  - `P(B|nao A)`;
  - diferenca absoluta de risco;
  - risco relativo;
  - lift;
  - odds ratio com correcao de continuidade;
  - Phi/Matthews;
  - intervalo de confianca de Wilson;
  - qualidade da estimativa.
- Removida linguagem funcional/causal da analise.
- Adicionado endpoint para mapa descritivo de associacoes ABC.
- Adicionado dataset temporal de predicao por intervalo com trava anti-vazamento.
- Adicionado painel frontend simples de ABC fechado.
- Criada pasta Supabase `supabase/abc_fechado` com SQL pronto para criar tabelas e seeds iniciais.

## Formulas implementadas

```text
P(B=1 | A=1) = N(A=1,B=1) / N(A=1)
P(B=1) = N(B=1) / N(intervalos observados validos)
Lift(A,B) = P(B=1 | A=1) / P(B=1)
RD = P(B=1 | A=1) - P(B=1 | A=0)
OR = (n11*n00) / (n10*n01)
phi = (n11*n00 - n10*n01) / sqrt((n11+n10)(n01+n00)(n11+n01)(n10+n00))
```

## Decisoes estatisticas

- Pearson nao e exibido como tal; o modulo usa Phi/Matthews para associacao binaria.
- Odds ratio recebe correcao de continuidade quando ha celulas zero.
- Intervalos `not_observed` ficam fora do denominador.
- `null` nao e tratado como `false`.
- Interpretacao usa linguagem de associacao descritiva, nunca funcao confirmada.
