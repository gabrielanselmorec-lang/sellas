# 13_07_26_fix4 - Monitoramento de drift

## Alteracao

Foi criado `backend/app/ml/drift.py` para gerar estatisticas de referencia no treino e comparar os dados atuais com o baseline do modelo.

O drift calcula:

- deslocamento de media em z-score para variaveis numericas;
- distancia total de variacao para variaveis categoricas;
- status baixo, moderado ou alto.

## Motivo

Monitorar mudancas de dados que possam degradar desempenho ou invalidar a interpretacao clinica do risco.

## Endpoint impactado

- `GET /api/ml/drift`

## Teste

Adicionado `tests/bhave/test_drift_governance.py`.
