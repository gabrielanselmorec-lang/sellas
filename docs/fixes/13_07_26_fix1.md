# 13_07_26_fix1 - Adapter bHave configuravel

## Alteracao

O adapter `backend/app/services/bhave_client.py` deixou de depender de uma rota fixa `/behavior-records` e passou a aceitar configuracao do contrato da API bHave por variaveis/parametros:

- `SELLAS_BHAVE_RECORDS_PATH`
- `SELLAS_BHAVE_AUTH_SCHEME`
- `SELLAS_BHAVE_AUTH_HEADER`
- `SELLAS_BHAVE_RECORDS_KEY`
- `SELLAS_BHAVE_PAGE_PARAM`
- `SELLAS_BHAVE_PAGE_SIZE_PARAM`
- `SELLAS_BHAVE_NEXT_PAGE_KEY`
- `SELLAS_BHAVE_MAX_PAGES`

## Motivo

Permitir ajuste ao contrato real da API bHave sem alterar o pipeline de ML.

## Endpoints impactados

- `POST /api/config/bhave`
- `GET /api/config/bhave/contract`
- `POST /api/sync/bhave`

## Teste

Adicionado `tests/bhave/test_adapter_contract.py`.
