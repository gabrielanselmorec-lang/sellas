# 13_07_26_fix7 - Reparo do lxml no .venv

## Alteracao

Foi reinstalado `lxml` no ambiente `C:\sellas_project\.venv` para corrigir o erro:

```text
ImportError: cannot import name 'etree' from 'lxml'
```

## Motivo

O `python-docx` depende de `lxml.etree`. O ambiente ainda carregava um pacote compilado incompatível com o Python 3.12 do `.venv`.

## Comando executado

```bash
.\.venv\Scripts\pip.exe install --force-reinstall --no-cache-dir lxml
```

## Validacao

```bash
.\.venv\Scripts\python.exe -c "from lxml import etree; from docx import Document; print('lxml/docx ok')"
```

Resultado:

```text
lxml/docx ok
```
